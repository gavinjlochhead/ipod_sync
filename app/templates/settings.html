Play History Sync
Rockbox must have Last.fm scrobbling enabled in Settings → General Settings → Playback → Last.fm Log. This creates /.scrobbler.log on the iPod, which is read at the start of each sync and archived afterwards. Tracks are matched by title + artist and marked played in Jellyfin.

GPIO Buttons & LEDs Disabled

Wire physical buttons and status LEDs to the Pi's GPIO header (BCM numbering). Every field is optional — leave a pin blank to skip that button/LED. Buttons go to GND (internal pull-up is used); LEDs need a series resistor to GND.

Buttons
LEDs
Mounted LED is on while the iPod is mounted. Removable LED is on while it is safely unmounted (OK to unplug). Syncing LED flashes while a sync is running. Requires the gpiozero package on the Pi (installed automatically by install.sh).
Triggering Eject from Home Assistant
Via MQTT (auto-discovery, recommended)

When MQTT + auto-discovery is enabled, a button entity called Eject iPod is automatically created in Home Assistant. It is only available when the iPod is connected. Use it in automations like any other button: 

automation:
  - alias: "Eject iPod after sync"
    trigger:
      - platform: state
        entity_id: sensor.ipod_sync_status
        to: "idle"
        for: "00:00:10"
    condition:
      - condition: state
        entity_id: button.eject_ipod
        attribute: available
        state: true
    action:
      - action: button.press
        target:
          entity_id: button.eject_ipod

You can also publish directly to the MQTT topic ipod_sync/eject/set with any payload to trigger the eject.

Via REST command (no MQTT needed)

Add this to your Home Assistant configuration.yaml then call rest_command.eject_ipod from any automation or script: 

rest_command:
  eject_ipod:
    url: http://<pi-ip>:8000/api/eject
    method: POST

Returns {"ok": true, "message": "…"} on success, or HTTP 409 if a sync is still in progress.
